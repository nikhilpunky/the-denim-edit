# The Denim Edit

Build a simple, modern website for a jeans business.

Create a clean homepage with:

Hero section with a strong jeans product image

Brand name and short tagline

Shop Now button

Featured jeans/products section

About the brand section

Why choose us section

Contact / WhatsApp button

Simple footer with social media links

Use a premium fashion-style design with a clean layout, bold typography, and minimal colors. Make it fully responsive for mobile and desktop.
